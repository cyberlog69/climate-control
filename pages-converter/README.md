# 🍏 Offline Apple `.pages` Converter (GUI & CLI)

A **100% offline**, privacy-first desktop application and command-line utility to convert Apple Pages (`.pages`) documents into **PDF**, **Microsoft Word (`.docx`)**, **Plain Text (`.txt`)**, and extract all embedded high-resolution media assets without requiring an active internet connection, external cloud services, or an Apple device.

---

## 🌟 Key Features

- **⚡ 100% Offline & Private**: All conversion processing happens locally in your computer's RAM. No files or text ever leave your device.
- **📄 Pixel-Perfect Vector PDF**: Extracts Apple's native embedded vector rendition (`QuickLook/Preview.pdf`) preserving typography, tables, and formatting.
- **📝 Word Document (.docx) Synthesis**: Reconstructs structured Word documents from vector streams and text hierarchies using `pdf2docx` and `python-docx`.
- **📋 Clean Plain Text (.txt)**: Instant text extraction for search indexing, note-taking, or NLP pipelines.
- **🖼️ High-Res Asset Extraction**: Extracts embedded photos, figures, and diagrams into a dedicated asset folder.
- **🖤 Sleek Dark-Themed Desktop GUI**: Modern AMOLED black & cyber cyan interface with multi-file queue, format checkboxes, and live progress bars.
- **💻 Full Command-Line Interface (CLI)**: Powerful CLI tool supporting recursive directory scanning and custom output destinations for automation scripts.
- **🚀 1-Click Windows Launcher**: Double-click `run_gui.bat` to launch the app instantly.

---

## 🚀 Quick Start (Desktop GUI)

Simply double-click:
```cmd
run_gui.bat
```
*The launcher will automatically verify the local virtual environment and launch the desktop window.*

Or launch manually via terminal:
```powershell
cd pages-converter
.\.venv\Scripts\python.exe gui.py
```

---

## 💻 Command-Line Interface (CLI)

### 1. Convert a single file:
```powershell
.\.venv\Scripts\python.exe cli.py "sample.pages" --format pdf,docx,txt
```

### 2. Convert all `.pages` documents in a folder:
```powershell
.\.venv\Scripts\python.exe cli.py "C:\Users\username\Documents\PagesFiles\" --output "C:\Users\username\Documents\Converted\"
```

### 3. Recursive directory scan:
```powershell
.\.venv\Scripts\python.exe cli.py "C:\Projects\" --recursive --output "./output"
```

### CLI Options Reference:
| Option | Short | Description | Default |
| :--- | :--- | :--- | :--- |
| `inputs` | | One or more `.pages` files or directories | *(Required)* |
| `--format` | `-f` | Target formats (`pdf`, `docx`, `txt`, `assets`, or `all`) | `pdf,docx,txt,assets` |
| `--output` | `-o` | Destination directory for converted files | Beside input file |
| `--recursive` | `-r` | Recursively scan subdirectories for `.pages` | `False` |

## 🏗️ Architecture & How It Works

Apple `.pages` files are ZIP archives composed of:
1. **`QuickLook/Preview.pdf`**: A high-resolution vector PDF generated by Apple Pages during document save.
2. **`Data/`**: Raw original assets (JPEG, PNG, HEIC, TIFF, audio/video).
3. **`Index/*.iwa`**: Snappy-compressed Protobuf binaries containing paragraph styles, character runs, and tables.

The converter inspects the internal ZIP structure, extracts the vector PDF directly for lossless fidelity, reconstructs Word documents and plain text, and unpacks the embedded media files into a companion assets directory.
